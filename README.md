# stocks-cert — Halal Stock Screener SPA

Static Vue 3 SPA (CDN, no build step) replicating [musaffa.com/stock-screener](https://musaffa.com/stock-screener/?country=US&page=1), hosted on GitHub Pages. Data is fetched periodically by GitHub Actions into `data/stocks.json` (Option A).

See `PLAN.md` (living plan) for phases and progress.
